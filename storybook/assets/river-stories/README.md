# River Stories artwork — Chapter 04 / Stage 09

Three WebP files with tracked dimensions, byte sizes and hashes are recorded in manifest.json.

- source/river-source.webp: archival compressed source of the original purpose-generated landscape pencil/crayon painting.
- exports/river-desktop.webp: optimized wide painting, no text embedded in artwork.
- exports/river-mobile.webp: portrait crop chosen around the willow and stream for the Stage 09 mobile experience. **Not an independently illustrated mobile painting**; should receive a mobile-native artwork review in Stage 14.

Accessibility and truthfulness: both notebook entries remain explicitly **not published**; links only jump to two native details entries containing working questions, never to invented articles.
