# Character assets — Paperkeeper / Stage 05

Canonical reference: `docs/forest/05-character-bible.md` and locked `docs/forest/ART-DIRECTION-LOCK.md`.

**Published/usable:** four transparent full-size Paperkeeper turnarounds (`front`, `three-quarter`, `profile`, `back`); five low-resolution action-key previews (`walk-a/b/c`, `read`, `rest`); **only** `moth.guide` and `roundbird.idle`; silhouette and small-scale test atlases.

**Source material:** `source/paperkeeper-turnaround-source.webp`, `source/paperkeeper-actions-source.webp` — purpose-created digital illustration sheets. The action source contains noncanonical exploratory animals; they are rejected and **not** exported as cast assets. Nothing was cut out of the flattened V2 masterboard. Artwork was image-generation assisted and is not claimed to be physically hand-drawn.

**Metadata:** `manifest.json` contains exact file hashes (SHA-256), dimensions, masks and source bboxes. Static character library at `/lazarusdev/storybook/character-lab/`. Generator and audits at `scripts/forest_character_export.py`, `scripts/forest_character_audit.py`, and `scripts/forest_character_smoke.mjs`.

**Not yet available:** complete layered chapter scenes, production-sized walk cycle, motion controller, character sound, contact interactions. Stage 06 onward requires separately approved scene artwork, Stage 11 handles animated timing.
