# R15A — Paperkeeper: source-derived production export

This folder documents asset cleanup for R15A, following the [binding seven-stage specification](./PAPERKEEPER-ASSET-RECONSTRUCTION.md).

The non-destructive source pipeline in `scripts/forest_r15a_export.mjs` reads the real R02 entrance hero and older Stage05/R11 transparent WebP poses, removes obvious red-key artifacts and low-alpha white-matte contamination, registers 9 poses to **128×144** cells with a consistent **y=133** groundline and writes a new `1152×144` journey sprite. The original thirteen Stage05 exports and approved painted backgrounds are never overwritten. The four-tone proof pages allow real alpha review over cream, deep forest, blue river and black. ImageGen-assisted character sketches belong to design exploration and are not falsely relabeled as complete handmade original digital painting.

`ASSET-AUDIT.json` is generated by the pipeline, with each source SHA256, actual canvas and alpha occupancy. `ANCHOR-MANIFEST.json` declares every generated pose, output hash, per-frame bounds, baselines and actual source.

**Critical narrative boundary:** the older `reach` journey keyframe is a limited compositional stand-in. `read` is a genuine seated reader and **not an actual hand-lifting pose**. Complete hand-specific `look-down / set-lantern / reach / lift / carry` illustrations must be drawn and registered separately before approving R16. Do not declare those assets as completed based only on a renamed file or simple CSS transform.

**Stage status:** asset-export candidate. Browser scene integration, collision measurement, and human material inspection are additional R15A gates.
