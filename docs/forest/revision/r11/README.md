## Art-direction correction

R10 repaired the invisible atlas gesture and restored original painterly mobile WebPs. The four principal painted chapters and native control architecture are preserved; R11 strengthens motion **at the control being used**, not through additional decoration, parallax, or generic opacity effects.

- **Path:** Move the existing real "Reveal the whole route" button into the illustrated frame rather than below it. Activate a finite 720ms stroke-dash ink drawing. The reverse operation restores native passive scroll tracking; neither hijacks scrolling or moves focus.
- **Work:** A selected hanging physical folio makes one short, damped hinge gesture. Its actual opened native disclosure draws an irregular pencil underlining beneath the paper title. Clicking the hanging link may navigate to the disclosure; the drawn underline remains in that target viewport.
- **River:** An opened native notebook entry draws three irregular waterlines directly below its heading, not on a remote decoration that has already scrolled offscreen.
- **House:** The authentic painterly mobile cottage and properly registered native window glow from R10 remain the functional action. R11 does not invent a new character pose or overwrite the genuine artwork.

## Visual discipline and omissions

- Zero new whole-body CSS Paperkeeper puppet animation, fake character frames or single-color glow-card transitions.
- Desktop and mobile use the rich original raster scene art restored in R10. The obsolete simplified SVG portraits remain hidden.
- No new full R05 replacement paintings or anatomically authored R06 character sprites are claimed. A separate generated House portrait study exists in the creative asset library but is **not** yet a versioned GitHub source asset and is not referenced by production.
- Typography, original five chapters, native anchors, truthful concepts, and Field Letter remain intact.

## Quality assurance

`npm run check:r11` checks both compiled entrypoints at 390px and 1440px for control placement **inside** the visible scene, real 720ms stroke progress, opened native folio and river ink, no page overflow and bounded chapter seams. Separate no-JS and reduced-motion tests assert native fallbacks without animation. R02–R04, Stage07, Stage14, Stage16, R08/R09 must remain green.

All automated diagnostics are text-only. No screenshots, video, trace or browser recordings are produced. Artist approval of full repaint remains an outstanding gate.
