# R05 — Four-chapter illustration continuity pass

17 November 2026 · production branch `feat/r02-entrance`.

## What has actually shipped

Four purpose-authored, small chapter-specific pencil-engraving SVG companions, with independent silhouettes, path geometry and placement:
- Winding Path: root/waymark on the trail, separate from the native tracing path and moth.
- Work Clearing: hanging-paper and thread motif, beneath the three actual folios.
- River Stories: water ripple and leaf mark, outside the actual stone navigation.
- House on the Hill: small amber window engraving, not an imitation of the real cottage's pixel-aligned window glow.

These are **secondary marginal drawings**, not replacements for the existing original AI-assisted raster paintings. The four main painted scenes, four separately composed native portrait SVGs, existing live text, concept labels, character images, mobile fallbacks and window alignments remain unchanged. No unverified independent painted portrait commissions or new gesture sprites are claimed.

## Decision

The verified original landscape paintings are more materially sophisticated than a wholesale algorithmic SVG replacement. Rather than degrade the user's anti-generic goal, this revision adds individually hand-directed engraved motifs and leaves full new desktop/portrait painting redraws as an **unresolved art-production requirement**. Source truth is explicit: R05 does **not** satisfy the original full-background repaint acceptance gate. R06/R07 can refine motion/typography honestly, but no automatic engineering test may masquerade as aesthetic approval.

## QA

New marks are decorative and never intercept input. Both HTML entries point to the same four SVG assets with route-relative paths. Existing art remains the source of scene identity. Compare visual composition manually on a genuine browser before artistic signoff; DOM tests only establish decode, stacking and functional invariants. No screenshots/videos captured automatically.
